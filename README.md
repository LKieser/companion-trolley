# Companion Trolley
An autonomous follow-me trolley that tracks a target using Ultra-Wideband (UWB) positioning and navigates safely using ROS2-based obstacle avoidance.

## Overview
This follow me trolley is designed to:
1. Carry objects for the user while following them
2. Avoid obstacles on the path to the user
3. Stay put and come when commanded so long as the user is close
